3. WHICH HOUR GETS WHICH RATING (implement exactly)

	hours("HH:MM") = HH + MM/60

	hourRating(h):                 // h = 6..18; the hour button covers [h, h+1)
	  pick = null; ov = 0
	  for each window w in windows:
	    a = hours(w.start); b = hours(w.end)
	    if a is NaN or b is NaN or b <= a: continue
	    o = min(b, h+1) - max(a, h)       // overlap in hours
	    if o > ov + 1e-9: ov = o; pick = w   // largest overlap wins; ties keep the earlier window
	  return ov >= 0.5 ? pick : null       // needs at least 30 minutes inside the window

	Precedence per hour:
	  1. If the hour is the existing BEST hour → unchanged (BEST wins over everything).
	  2. Else if hourRating(h) returns a window → that window's rating.
	  3. Else → existing wind-band label, unchanged.

	Worked example with the sample data: 6–9 AM wind labels (unchanged) · 10 AM BEST (unchanged) · 11 AM CONDITIONAL · 12 PM CONDITIONAL (tie 0.5/0.5 keeps the earlier window) · 1 PM AVOID · 2 PM AVOID · 3–6 PM wind labels (unchanged).
