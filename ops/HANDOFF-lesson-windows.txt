5. TIMING THROUGH THE DAY (hour strip)

5.1 Which window an hour belongs to (pure function; implement exactly)

	hourWin(h):            // h = integer hour 6..18; the hour covers [h, h+1)
	  best = null; ov = 0
	  for each window w:
	    a = hours(w.start); b = hours(w.end)        // "09:30" -> 9.5
	    o = min(b, h+1) - max(a, h)                 // overlap in hours
	    if o > ov + 1e-9: ov = o; best = w          // largest overlap wins; ties keep the earlier window
	  return ov >= 0.5 ? best : null                // an hour needs at least 30 min inside a window

Examples with windows 09:00–10:30 BEST, 10:30–12:30 CONDITIONAL, 12:30–15:00 AVOID:
	9 AM → BEST · 10 AM → BEST (10:00–10:30 is BEST 0.5 h, CONDITIONAL 0.5 h; tie keeps the earlier, BEST) · 11 AM → CONDITIONAL · 12 PM → CONDITIONAL (0.5 h each; tie keeps the earlier) · 1 PM, 2 PM → AVOID · 3 PM → none · 6–8 AM → none.

6. TIME FORMATTING (implement exactly)

	hours("HH:MM") = HH + MM/60
	short(t) = (h%12 || 12) + (m ? ":" + two-digit m : "")
	range(start, end):
		if both AM or both PM:  "{short(a)}–{short(b)} {AM|PM}"        e.g. "9–10:30 AM"
		else:                   "{short(a)} {A}–{short(b)} {B}"         e.g. "10:30 AM–12:30 PM"
	Use an en dash (–), no spaces. 12:30 is PM. 12:00 noon is "12 PM".
